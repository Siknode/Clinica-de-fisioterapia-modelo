# 🌿 Clínica Fisiovita — Site Modelo de Fisioterapia & Pilates

Template moderno, responsivo e de alta conversão desenvolvido para clínicas de Fisioterapia, Estúdios de Pilates, Reabilitação Física e Saúde Integrativa.

Este projeto foi construído com foco em excelência visual, performance e usabilidade, incorporando o **Símbolo Oficial da Fisioterapia** (Tridente, Serpentes e Raio) e dados genéricos prontos para personalização.

---

## ✨ Principais Funcionalidades

- **🏛️ Identidade Visual com Símbolo Oficial:** Vetor SVG de alta qualidade do Símbolo da Fisioterapia com gradientes suaves.
- **⚡ Seções Completas:**
  - **Hero Section:** Apresentação de impacto, contadores animados e modal com vídeo institucional.
  - **Diferenciais:** 5 pilares de atendimento humanizado e multidisciplinar.
  - **Especialidades:** Fisioterapia Clínica, Pilates Clínico, Nutrição Integrativa, Fonoaudiologia, Musculação Terapêutica, Reabilitação Física e Fisioterapia Geriátrica.
  - **Para Quem:** Filtros interativos por queixas clínicas (Lombar, Cervical, Hérnia de Disco, Artrose, Pós-Operatório, Atletas, Idosos e Gestantes).
  - **Galeria da Estrutura:** Lightbox em tela cheia para apresentação das salas e aparelhos.
  - **Corpo Clínico & Depoimentos:** Apresentação da equipe com registros e avaliações de pacientes.
  - **🤖 IA Triagem Virtual:** Questionário interativo em 3 passos com diagnóstico prévio e integração com WhatsApp.
  - **Blog Científico & FAQ:** Artigos de saúde e acordeão de perguntas frequentes.
- **📱 100% Responsivo:** Adaptado perfeitamente para celulares, tablets e desktops.
- **🚀 Deploy Fácil:** Totalmente compatível com **Vercel**, **Netlify** e **GitHub Pages**.

## 🚀 Como Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/SEU_USUARIO/clinica-fisioterapia-modelo.git
   cd clinica-fisioterapia-modelo
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```
   Acesse [http://localhost:5173/](http://localhost:5173/) no seu navegador.

4. **Gerar build de produção:**
   ```bash
   npm run build
   ```

## ☁️ Como Enviar para a Vercel

### Opção 1: Via CLI da Vercel
```bash
npx vercel
```

### Opção 2: Conectando com o GitHub
1. Faça o push deste repositório para o seu GitHub.
2. Acesse [vercel.com](https://vercel.com) e clique em **Add New Project**.
3. Importe o repositório e clique em **Deploy**.
